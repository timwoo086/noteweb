# 影片库 JavLib（1Panel 本地应用）

按编号从 JavBus / JavDB 抓取影片信息与封面，本地归档；下载地址、录入时间等由自己补录；可按**发行时间 / 录入时间**（可切换）或演员名检索。带登录密码保护。

## 功能

- 输入编号（如 `ABP-123`），自动抓取标题、演员、发行时间、封面，两站结果互补合并
- 封面下载到本地，避免外链失效
- 手动补录：下载地址、录入时间、分辨率（1080P/4K）、帧率（文本框手动填写）、原盘/蓝光/Remux 三个复选项、备注
- 卡片网格展示，属性以彩色标签显示（分辨率/原档/REMUX/帧率）
- 每张卡片一个「复制」按钮：点击即复制下载地址（下载与复制合并为一个按钮）
- 内置 avdb 演员映射表（26088 位演员、6 万条别名），刮削后演员名自动归一为统一中文名；同一演员的多个写法（日文/罗马字/繁体/中文）都指向同一个名字
- 演员若有多个写法（如 `田中柠檬 / 楓カレン / 枫可怜 / Karen Kaede`），录入弹窗里会列出候选按钮，点一下即可选中；编辑旧记录时也能重新选
- 「演员别名」里手动设置的分组优先级最高，可覆盖自动归一结果
- 日期标题前带复选框，勾选即可选中该日期下全部影片一键复制；卡片右下角多选框只保留方框
- 卡片列表用压缩缩略图加快加载，点进详情页才显示原清晰度海报（旧数据没有缩略图时自动回退原图）
- 点击卡片封面或标题进入影片详情页，参考 JavBus 风格：左侧大图封面，右侧番号/标题/演员/发行与录入时间/分辨率/帧率/原档/REMUX/备注，可直接复制下载地址或跳回编辑
- 卡片标签（分辨率/原档/REMUX/帧率）放在标题上方，不再压在封面上
- 点击卡片上的演员名，自动筛出该演员全部影片
- 「演员别名」设置：把同一演员的多个名字（如 RION / りおん / 梨音）归为一组，点任一名字都能筛出整组；第一行为统一显示名
- 卡片上的「多选」勾选框 + 顶部「全选 / 一键复制下载地址」，批量复制每行一个地址
- 删除入口在编辑弹窗内，不再占用卡片按钮
- 列表按当前日期模式分组显示（如「2025年8月16日」「2025年8月15日」），每组带数量，最新日期在最上
- 检索：发行时间 / 录入时间双模式切换 + 日期区间 + 演员 + 编号/标题关键字
- 登录密码保护

## 零、直接拉镜像部署（最简单，推荐）

镜像已由 GitHub Actions 自动构建并发布到 GHCR（公开，无需登录即可拉取）：

```
ghcr.io/timwoo086/noteweb:latest
```

**在 1Panel 里：** 左侧「容器」→「编排」→「创建编排」，把本仓库的 `compose.yaml` 内容粘贴进去，点「启动」即可。服务器无需源码、无需构建。

**或用命令行：**

```bash
# 把 compose.yaml 放到任意目录，然后：
docker compose -f compose.yaml up -d
```

部署后访问 `http://服务器IP:5000`，默认密码 `admin`（可用环境变量 `APP_PASSWORD` 修改）。数据与封面持久化在 `./data` 目录。

> 每次 push 到 GitHub main 分支会自动重建并更新 `latest` 镜像；服务器执行 `docker compose pull && docker compose up -d` 即可升级。

## 一、在 1Panel 中安装（本地应用包方式，可选）

本项目是符合 1Panel 规范的**本地应用包**。安装步骤如下：

1. 把本目录（`javlib/`）整个上传到服务器的 1Panel 本地应用目录：

   ```bash
   # 1Panel 本地应用默认目录（若你的版本不同，以实际路径为准）
   /opt/1panel/resource/apps/local/
   ```

   上传后应形成：`/opt/1panel/resource/apps/local/javlib/`，其下包含 `data.yml`、`logo.png`、`README.md`、`1.0.0/`。

2. 登录 1Panel → 左侧「应用商店」→ 右上角切换到「**本地应用**」标签。

3. 找到「**影片库**」，点「安装」。安装表单可填：
   - **HTTP 端口**：对外访问端口，默认 `5000`
   - **登录密码**：网页登录密码（默认 `admin`，建议修改）
   - **会话密钥**：保持默认或改成一段随机字符串
   - **HTTP 代理**：目标服务器能直连两个站点时**留空**；不能直连时填 `http://代理地址:端口`

4. 等待构建完成（首次会从国内镜像源装依赖，约 1-3 分钟）。

5. 安装后在「容器」中看到 `javlib-xxxx` 容器即成功。浏览器访问：

   ```
   http://服务器IP:端口
   ```

   输入安装时设置的密码进入。

> 数据持久化：数据库和封面都在版本目录的 `data/` 下，并已映射到容器 `/app/data`。**升级/重装前请备份 `data/` 目录**。

## 二、本地直接运行（无 Docker，开发调试用）

在 `1.0.0/` 目录下：

```bash

pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com
python app.py
```

浏览器打开 `http://localhost:5000`，默认密码 `admin`。

## 四、常见问题

- **抓取失败 / 字段为空**：站点可能改版或需要代理。先在表单填代理试；若某字段长期抓不到，可在录入弹窗里手动补填——抓取失败不阻断入库。
- **改版后抓不到**：编辑 `scraper.py` 顶部的 `TITLE_SELECTORS / ACTRESS_SELECTORS / DATE_LABELS / COVER_SELECTORS` 即可，无需改其他代码。
- **忘记密码**：进入容器执行 `export APP_PASSWORD=新密码` 后重启，或用 1Panel 重新安装并设置新密码。
- **端口访问不到**：检查 1Panel 防火墙/安全组是否放行该端口。
